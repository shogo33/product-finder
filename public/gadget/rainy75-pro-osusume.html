なぜ「Rainy75」は全ガジェットブロガーから大絶賛されているのか？

正直に言います。WORKEYのRainy75シリーズに初めて触れたとき、「これが1万円台？」と声に出てしまいました。

アリエクで中華キーボードを10台以上沼ってきた自分でも、このコスパの衝撃は久しぶりでした。アルミ削り出し筐体・ガスケットマウント・ホットスワップ対応——この3点が同時に刺さってくるキーボードが、3万円を切る価格帯に存在している事実。それがRainy75シリーズの本質です。

アルミ筐体の圧倒的な重厚感と「コトコト」響く極上の打鍵音

Rainy75 Proのケースは、アルミ合金の削り出し。手に持った瞬間の重さが「違う」とすぐわかります。

ポリカーボネートや安価なABSプラスチック筐体のキーボードと並べると、その差は一目瞭然です。アルミの質量感が土台としての安定性を生み、打鍵時のたわみや滑りをゼロに近くします。

そして「コトコト音」の正体ですが、これはアルミの重量感がもたらす反響と、ガスケット構造の弾性が掛け合わさった結果です。

  • アルミケースが音を適度に反響・増幅させる
  • ガスケットのシリコンクッションが高周波の「カチカチ音」を吸収する
  • 結果として残るのが、低めでこもった「コトコト」という打鍵音

この音は一度聴いたら忘れられない。タイピング中毒になる人が続出しているのも、当然の話です。

75%レイアウトとガスケットマウント：この組み合わせが生む打鍵体験

75%レイアウトは、テンキーレス（TKL）よりさらにコンパクトですが、方向キーとファンクションキーをしっかり確保しています。

デスクスペースが広がり、マウスとの距離が縮まる。それだけで作業効率とゲームプレイが変わります。

そこにガスケットマウントが加わることで、タイピング時の「手への衝撃」が驚くほど和らぎます。PCBがケースに直接固定されておらず、ガスケットを介してフローティング状態になっているため、押下時の反発が柔らかい。長時間タイピングしても手が疲れにくいのは、この構造のおかげです。

「3万円クラスの打鍵感が1万円台で買える」というコンセプトは、決して誇張ではありません。実際にLeopold FC750RやHHKBなどのプレミアム帯と比較しても、打鍵音・打鍵感のクオリティは肉薄しています。

実際の打鍵感と音：「コトコト」が生まれる理由

Rainy75 Proの打鍵音は、単なる「静かなキーボード」とは違います。

音には「存在感」があります。コトコト、コトコト——低く、こもっていて、でも上品。ABS板打ちの「パカパカ」でも、プラ筐体の「カコカコ」でもない、独自の音域です。

この音が生まれる仕組みは3層構造です：

  1. アルミケースの質量：重量のある筐体が振動を吸収しつつ、適度に音を反響させる
  2. ガスケットの弾性：PCBが直接固定されず、シリコンガスケットを介してフローティング状態。高周波ノイズをカットする
  3. フォームとPEフィルム：多くのRainy75 Proには内部に吸音フォームが施されており、さらに音を整える

この3層が重なって初めて、あの「コトコト音」が完成します。

【注意】Rainy75に「日本語配列（JIS）」はある？現状と入手方法

「Rainy75 ProってJIS配列あるの？」——これは日本人購入者が必ず突き当たる壁です。

JIS版の現状：WORKEYが日本語配列モデルを展開中——ただしアリエク在庫は流動的

結論から言うと、WORKEY公式はRainy75 Proの日本語配列（JIS）モデルを展開しています。

ただし、アリエクでの在庫状況は通常のUS配列版に比べると少なく、「在庫あり」の状態が安定していません。入荷タイミングやセール時期に合わせて購入するか、プレオーダーを活用するのが現実的です。

JIS版を確実に手に入れるためのポイント：

  • WORKEYの公式アリエクストアをお気に入り登録しておく
  • 「Follow Store」ボタンを押して新着入荷通知をオンにする
  • 11.11・6.18などの大型セール直前にプレオーダーが開始されることが多い
  • 商品ページのオプション一覧で「JIS」「JP」「Japanese Layout」の表記を探す

キーマップ変更ツール「QMK / VIA」対応で自分好みに配列カスタマイズ可能

もしJIS版の在庫がなかった場合でも、諦める必要はありません。

Rainy75 ProはVIA対応のPCBを搭載しているため、US配列の物理キーボードを購入してからソフトウェアでキーマップをJIS風に変更できます。

VIAでのキーマップ変更手順（簡易版）：

  1. VIAの公式サイト（usevia.app）にアクセス
  2. Rainy75 ProをUSBで接続する
  3. ブラウザ上でキーボードが自動認識される（されない場合はJSONファイルを手動でロード）
  4. キー配置をドラッグ＆ドロップで変更・保存

「¥」や「む」などの日本語キーをどこかに割り当てれば、実用上はJIS配列と同等の操作が可能です。

VIA対応の確認方法は、アリエクのRainy75 Proショップページの商品説明内に「VIA」「QMK」という表記があるかどうかを確認してください。現行モデルのほぼすべてが対応しています。

Rainy75の「説明書」が不親切？基本操作とショートカット一覧

「説明書が英語と中国語しかない」——これはRainy75シリーズに限らず、中華キーボード全般に共通する「あるある」です。

有線・Bluetoothの切り替え方法（接続手順）

Rainy75 Proはトリプルモード対応（有線USB / Bluetooth / 2.4GHzワイヤレス）です。

Bluetooth接続手順：

  1. キーボード背面またはサイドのスイッチで「BT」モードに切り替える
  2. Fn + Q（またはFn + 1/2/3）を長押しでペアリングモードに入る
  3. PC・スマートフォン側のBluetooth設定で「Rainy75」を選択してペアリング完了
  4. 接続先の切り替えはFn + 1 / 2 / 3キーで対応デバイスを呼び出す

有線モードへの切り替え：

  • 背面スイッチを「USB」側に切り替えてからケーブルを接続するだけ

Rainy75 RTモデル（HEスイッチ）も視野に入れるべきか

Rainy75シリーズにはタイピング特化のProだけでなく、ゲーミング特化の「RTモデル」も存在します。

RTモデルとは：磁気ホールエフェクトスイッチとラピッドトリガーの解説

Rainy75 RT（またはHE Lite）は、Hall Effect（磁気ホールエフェクト）スイッチを搭載したモデルです。

ホールエフェクトスイッチの最大の特徴は「アクチュエーションポイントを自由に設定できること」と「ラピッドトリガー機能」です。

  • ラピッドトリガー：キーを少し押しただけで入力が発火し、わずかに離しただけでリセットされる。FPSでのストレイフやジャンプの入力速度が劇的に向上する
  • アクチュエーションポイントの調整：0.1mm単位でキーの反応する深さを設定できる
  • 耐久性：機械接点がないため、従来のメカニカルスイッチより理論上の耐久性が高い

ただし、打鍵音と打鍵感のクオリティはRainy75 Proに軍配が上がります。RTモデルはゲームに全振りした設計です。

タイピング用ならPro、FPS用ならRT——用途別最終結論

迷っている人に向けて、シンプルに結論を出します。

  • 毎日のタイピング・コーディング・ライティングメイン → Rainy75 Pro
  • Valorant・Apex・CS2などのFPSで勝ちたい → Rainy75 RT/HE Lite
  • 両方やりたい → まずProを買って、後でRTを追加するのがベスト

同じRainy75シリーズというブランドの安心感があるので、片方を使ってから追加するという選択肢も十分ありです。

Rainy75 Proに関するよくある質問（FAQ）

Q1. Rainy75 Proは初心者でも組み立て・使用できますか？

完成品（スイッチ＋キーキャップ付き）を選べば、箱から出してケーブルをつなぐだけで即使えます。ホットスワップ対応なので、スイッチ交換もハンダなしでできるため、カスタム初心者でも安心です。ガジェット好きの最初の1台として非常に適しています。

Q2. Rainy75 Proと通常版Rainy75の違いは何ですか？

最大の違いはケース素材です。通常版はポリカーボネートまたはアクリル、Proはアルミ合金削り出し。この差が重量・打鍵音・質感のすべてに影響します。打鍵音の「コトコト感」と重厚な所有感を求めるなら、間違いなくRainy75 Proです。

Q3. Rainy75 ProはQMK/VIAに対応していますか？

対応しています。VIAのウェブアプリ（usevia.app）からブラウザ上でキーマップを自由に変更できます。キーの割り当て・マクロ・RGBエフェクトもすべてGUIで設定可能です。難しいコマンドは一切不要です。

Q4. 日本語配列（JIS）版はアリエクで買えますか？

WORKEY公式がJIS配列モデルを展開していますが、アリエクでの在庫は流動的で常に在庫があるとは限りません。WORKEYのアリエクストアをフォローして入荷通知を受け取るか、US配列版を購入してVIAでキーマップを変更する方法が現実的な選択肢です。

Q5. Rainy75 Proに合うおすすめのキーキャップはありますか？

MX互換の75%レイアウト対応キーキャップであれば基本的に装着できます。South-facing PCBのため、背の高いキーキャップ（Cherry/SAプロファイル）との干渉が出にくく、色々なデザインを楽しめます。アリエクではDye-subキーキャップが安くて品質も高くおすすめです。
